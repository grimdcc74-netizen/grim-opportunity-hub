# GRIM Opportunity Hub

Dashboard personale per opportunità WORK / VFX / CGI / AI, ART, GRAFFITI / WRITING / MURALISM e, in una fase successiva, PHOTOGRAPHY.

Il frontend legge a runtime il feed pubblico da `grim-opportunity-data`. I dati privati saranno collegati successivamente tramite Supabase Free.

## Sviluppo locale

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
